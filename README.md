# Task Manager

A browser-based task manager that organizes tasks in an Eisenhower matrix by
priority and deadline. Tasks are read from and saved to a Supabase `tasks`
table.

## Run locally

From the repository root, start a static web server:

```sh
python3 -m http.server 8000
```

Open [http://localhost:8000/front-end/](http://localhost:8000/front-end/).

## Connect Supabase

1. Create a Supabase project and a `public.tasks` table with these columns:

   ```sql
   create table public.tasks (
     id bigint generated by default as identity primary key,
     name varchar(120) not null,
     description text not null,
     priority varchar(20) not null,
     deadline date,
     completed boolean not null default false
   );

   alter table public.tasks enable row level security;
   ```

2. Set `supabaseUrl` and `supabaseKey` in `front-end/script.js` to your
   project's URL and publishable key.
3. Configure Supabase Row Level Security policies for the users and access
   model you intend to support. The page has no sign-in flow, so private
   per-user policies require adding authentication before they can be used.
   Do not put a Supabase `service_role` key in browser code. A publishable key
   is intended for the browser, but it does not replace access policies.
